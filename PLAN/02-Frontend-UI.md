## Task 1: 실시간 효과 시각화

### effectEngine 결과를 UI에 반영

`effectMap`의 각 슬롯 값에 따라 시각적 피드백을 제공한다.

```
effectMap["2-3"] = 5   → 해당 칸에 파란 오버레이 + "+5" 뱃지
effectMap["1-0"] = -2  → 해당 칸에 빨간 오버레이 + "-2" 뱃지
effectMap["3-1"] = "ignore" → 회색 차단 마크
```

### 아티팩트 레벨 표시

```
enhancedLevel = artifact.level + effectMap[slotKey]

enhancedLevel > artifact.level → 초록색 레벨 뱃지 (버프)
enhancedLevel = artifact.level → 기본 표시
enhancedLevel < artifact.level → 노란색 뱃지 (디버프)
enhancedLevel ≤ 0             → 붉은색 + "파괴" + 아이콘 어둡게
```

```
│ 6 │ 7 │ 8 │ 9 │10 │11 │  row 1 (6열)
├───┼───┼───┼───┼───┼───┤
│12 │13 │14 │15 │16 │17 │  row 2 (6열)
├───┼───┼───┼───┼───┼───┤
│18 │19 │20 │21 │22 │23 │  row 3 (6열)
├───┼───┼───┼───┼───┼───┤
│24 │25 │26 │27 │28 │29 │  row 4 (6열)
├───┼───┼───┬───┘   │   │
│30 │31 │32 │33 │         row 5 (4열)
└───┴───┴───┴───┘

+ 슬롯 수 조절 버튼 (-, +)
```

### 인터랙션 정의

| 동작 | 트리거 | 결과 |
|------|--------|------|
| 아이템 배치 | 팔레트에서 드래그 → 빈 슬롯 드롭 | `placeItem()` → `recalculate()` |
| 아이템 이동 | 슬롯에서 드래그 → 빈 슬롯 드롭 | `swapItems()` → `recalculate()` |
| 아이템 스왑 | 슬롯에서 드래그 → 다른 아이템 위 드롭 | `swapItems()` → `recalculate()` |
| 석판 회전 | 우클릭 (rotatable인 경우만) | `rotateTablet()` → `recalculate()` |
| 아이템 제거 | 더블클릭 또는 팔레트로 드래그 | `removeItem()` → `recalculate()` |
| 슬롯 수 변경 | +/- 버튼 | `setSlotNum()` → 그리드 재구성 |

### 드래그 중 효과 미리보기

석판을 드래그 중일 때 → 마우스 아래 슬롯 기준으로 효과 범위를 미리 보여줌:
- 버프 영향 칸: **파란색 반투명 오버레이 + 값 표시**
- 디버프 영향 칸: **빨간색 반투명 오버레이 + 값 표시**
- 복합 석판: 해당 위치에서의 실제 효과를 미리 계산

## Task 4: 커스텀 석판 에디터 (`components/editors/CustomTabletModal.tsx`)

### 용도
Vision API 인식 불가 합성 석판, 또는 유저가 직접 효과를 정의하고 싶은 경우.

### UI 사양

```
┌────────────────────────────────────┐
│  커스텀 석판 효과 입력               │
│  이름: [______________]             │
│                                    │
│  5x5 그리드:                        │
│  ┌────┬────┬────┬────┬────┐       │
│  │    │    │ +1 │    │    │       │
│  ├────┼────┼────┼────┼────┤       │
│  │    │ +1 │ +2 │    │    │       │
│  ├────┼────┼────┼────┼────┤       │
│  │    │ +1 │ ★  │ -1 │    │  ★ = 본체
│  ├────┼────┼────┼────┼────┤       │
│  │    │    │ -1 │    │    │       │
│  ├────┼────┼────┼────┼────┤       │
│  │    │    │    │    │    │       │
│  └────┴────┴────┴────┴────┘       │
│                                    │
│  좌클릭: +1 반복클릭 +2,+3..+5     │
│  우클릭: -1                         │
│  Ctrl+클릭: 초기화                  │
│                                    │
│  [취소]                   [확인]    │
└────────────────────────────────────┘
```

### 동작
- 중앙 (2,2)는 본체 → 수정 불가
- 좌클릭: 0 → +1 → +2 → +3 → +4 → +5 → 0 (순환)
- 우클릭: 0 → -1 → 0 (토글)
- 확인 시: 5x5 → `Effect[]` 변환 (`{ dx: col-2, dy: row-2, value }`)
- effectType: 'simple'로 저장 (복합 로직 불가)
