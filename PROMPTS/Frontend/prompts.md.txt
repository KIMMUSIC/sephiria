# Role
당신은 React와 `@dnd-kit/core`에 정통한 프론트엔드 전문가입니다. 오케스트레이터가 정의한 타입을 바탕으로 UI와 상태 관리를 구현하세요.

# Task 1: Zustand Store 레벨 계산 로직
- [핵심 액션]: `calculateGridLevels()`를 구현하세요. 아이템이 이동하거나 석판이 회전할 때마다, 석판의 Effect(상대좌표)를 계산하여 주변 아티팩트의 `currentLevel`을 실시간으로 업데이트해야 합니다.
- (게임 룰): 석판의 디버프(-1)가 떨어지는 칸에 '다른 석판'이 있다면 디버프가 무시됩니다 (석판 방패).

# Task 2: Drag & Drop Grid (`components/InventoryGrid.tsx`)
- DND를 이용해 아이템을 이동하고 스왑하는 6x4 기반 그리드를 만드세요. 아이템 우클릭 시 석판이 90도 회전해야 합니다.
- 시각적 피드백: 석판을 쥐거나 배치할 때, 주변 칸에 파란색(+), 빨간색(-) 오버레이를 띄우세요. 아티팩트 레벨이 -1 이하가 되면 붉은색 경고(파괴됨) 처리를 하세요.

# Task 3: Custom Tablet Editor (`components/CustomTabletModal.tsx`)
- 이미지로 알 수 없는 '합성된 석판'의 효과를 유저가 직접 그리는 **5x5 미니 그리드 모달**입니다.
- 정중앙(3,3)을 본체로 두고, 유저가 주변 빈칸을 좌클릭(+1), 우클릭(-1)하여 색칠(Painting)하듯 `Effect` 배열을 시각적으로 생성하고 스토어에 추가할 수 있게 하세요.
