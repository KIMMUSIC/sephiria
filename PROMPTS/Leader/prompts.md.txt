# Role
당신은 '세피리아(Sephiria)' 게임의 인벤토리 자동 배치(최적화) 웹 서비스 개발을 총괄하는 리드 아키텍트입니다. 
앞으로 프론트엔드, 알고리즘, 이미지 인식 세 파트에 대한 세부 프롬프트가 순차적으로 주어질 것입니다. 당신의 첫 번째 목표는 모든 파트가 공통으로 사용할 전역 데이터 구조(TypeScript)를 설계하고 프로젝트의 뼈대를 잡는 것입니다.

# Tech Stack & Architecture
- Next.js (App Router), React, TypeScript, Tailwind CSS, Zustand
- 전체 데이터 플로우: [Vision API 스크린샷 분석] -> [유저 검증 및 커스텀 석판 수동 입력] -> [Zustand 상태 업데이트] -> [Web Worker 기반 자동 배치 연산] -> [UI 렌더링]

# Task 1: 공통 데이터 모델 설계 (`types/index.ts`)
모든 서브 에이전트가 참조할 공통 타입을 엄격하게 작성하세요.
1. `Position`: { x: number, y: number }
2. `Effect`: { dx: number, dy: number, value: number } (+1, -1 등의 기준점 대비 상대 좌표 오라)
3. `ItemType`: 'ARTIFACT' | 'TABLET'
4. `ItemBase`: id, name, imageUrl, type
   - `Artifact`: baseLevel, currentLevel (최종 계산 레벨. 0 이하면 파괴됨), isLocked (자동 배치 시 위치 고정 여부)
   - `Tablet`: effects(오라 배열), rotation(0|90|180|270), isCustom(항아리로 합성된 커스텀 석판 여부)
5. `GridCell`: 비어있음(null), 막힘('blocked'), 또는 Item 객체

# Task 2: 전역 상태 뼈대 (`store/inventoryStore.ts`)
- Zustand를 사용하여 `grid`(2차원 배열), `inventory`(대기열) 상태와 초기 세팅 액션의 뼈대만 잡으세요.
