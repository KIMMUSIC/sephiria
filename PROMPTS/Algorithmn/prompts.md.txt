# Role
당신은 최적화 알고리즘 엔지니어입니다. 메인 스레드(UI)가 멈추지 않도록 순수 TypeScript 기반의 **Web Worker**에 아이템 자동 배치 알고리즘을 구현하세요.

# Task 1: Scoring Function (채점 함수)
특정 배치 상태의 점수를 매기는 `evaluateBoard(board)`를 작성하세요.
- **[가점]** 모든 아티팩트의 `currentLevel` 총합
- **[절대 기피 룰]** 단 하나의 아티팩트라도 레벨이 -1 이하가 되어 파괴되었다면, 그 배치도는 무조건 폐기해야 하므로 총점에 `-99999점`을 부여하세요.
- **[장외 홈런 & 석판 방패 우대]** 디버프(-1) 방향이 그리드 바깥(없는 칸)을 향하거나, 다른 석판에 꽂힌다면 페널티가 증발하므로 추가 가점(+10점)을 주어 이 꼼수를 알고리즘이 적극 활용하게 유도하세요.

# Task 2: Simulated Annealing (모의 담금질) (`workers/optimizer.worker.ts`)
- 프론트에서 현재 그리드 상태를 입력받습니다.
- 무작위 두 아이템 위치 스왑 또는 무작위 석판 90도 회전을 변이(Mutation)로 사용합니다.
- 점수가 높으면 수용, 낮으면 온도(Temperature) 공식에 따라 확률적으로 수용하여 지역 최적해를 탈출합니다.
- 약 1.5초~2초 동안 수만 번 이 과정을 반복한 뒤, 가장 점수가 높았던 최종 `GridCell[][]` 상태를 메인 스레드로 `postMessage`를 통해 반환하세요.

[지시사항]
Worker 내부 로직과, 프론트에서 "최적 배치 찾기" 버튼 클릭 시 Worker를 호출하는 커스텀 훅(`hooks/useOptimizer.ts`)을 작성해 주세요.
